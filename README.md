# HI1031-LAB1

Element som måste finnas:
Signup page för kunder.
Användar identifiering (login), förskapade uppgifter för admin.

Olika behörighets klasser (kund, admin, lager personal).
Metodanrop kräver behörighet.

Administratör: Kan skapa inloggningsuppgifter för lagerarbetare. Byta personals lösenord, ta bort användare(?). Kan också redigera varor.


Lagerarbetare: Se varulager visar om varan finns i lager eller inte. Redigera varor, ändra dess namn, kategori. Se kunders ordrar och kunna "packa" dem.

Kund: Skapa inloggningsuppgifter och logga in. Se varukatalog och lägga till varor till varukorg, ta bort varor från korgen och avsluta köpet. Eventuell att se sin order och ifall den är packad eller inte.
